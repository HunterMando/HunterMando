## 🚀 Principais Projetos em Destaque

### 1. 🥗 [SafeNutri — Plataforma de Receitas para Restrições Alimentares](https://safenutri.com.br)
Sistema web Full-Stack em produção projetado para recomendar e filtrar receitas seguras validadas por nutricionistas para usuários com alergias, intolerâncias e restrições alimentares severas.
- **Backend ([safenutri-api](https://github.com/SafeNutri-IFTM/safenutri-api)):** API RESTful em **Java 25** e **Spring Boot**, persistência em **PostgreSQL** com controle de *migrations*, módulo de chat entre usuários e nutricionistas, documentação via **Swagger UI** e deploy automatizado com **Docker** e **GitHub Actions**.
- **Frontend ([safenutri-front](https://github.com/SafeNutri-IFTM/safenutri-front)):** Aplicação SPA construída com **Angular 21**, **TypeScript**, **Node.js** e **Tailwind CSS**, com geração de fichas de receitas em PDF e containerização via **Docker** e **Nginx**.

### 2. 🎓 [Gradua (SmartPrep) — Plataforma Mobile Gamificada para o ENEM](https://github.com/HunterMando/gradua-android)
Aplicativo Android nativo desenvolvido **100% em Kotlin** com **Jetpack Compose**, **Material Design 3** e arquitetura **MVVM**.
- Consome uma API RESTful em Python hospedada em nuvem (`PythonAnywhere`) utilizando **Retrofit 2**, **OkHttp**, **Gson** e **Kotlin Coroutines** (requisições assíncronas paralelas com `async`/`await`).
- Conta com geração algorítmica balanceada de simulados semanais, filtragem dinâmica em cascata por matéria e subtópico, favoritos sincronizados em nuvem, histórico de desempenho e *leaderboard* competitivo em tempo real.

### 3. 🧠 [Neural Networks & Deep Learning Implementations](https://github.com/HunterMando/neural-networks-deep-learning)
Repositório dedicado à implementação e análise de arquiteturas de Redes Neurais Artificiais em Python:
- **Perceptron de Camada Única** e **MADALINE** para reconhecimento de padrões.
- **Multilayer Perceptron (MLP)** com retropropagação do erro (*Backpropagation*), ajuste de hiperparâmetros e monitoramento de convergência.
- **Redes Neurais Convolucionais (CNNs)** com camadas de convolução, *pooling* e *fully connected*.

### 4. 📊 [Machine Learning & Data Science Portfolio](https://github.com/HunterMando/machine-learning-data-science)
Pipeline completo de experimentos de Ciência de Dados e Aprendizado de Máquina em Python:
- **Classificadores Supervisionados:** Treinamento comparativo e validação cruzada de modelos preditivos.
- **Agrupamento Não Supervisionado:** Segmentação de dados e descoberta de padrões com algoritmos de *Clustering*.
- **Séries Temporais:** Decomposição sazonal e previsão de demanda ao longo do tempo.

### 5. ⚽ [Sistema Full-Stack de Bolões e Apostas](https://github.com/HunterMando/bolao-web2-app)
Aplicação web completa desenvolvida com backend em **Node.js (Express & TypeScript)**, modelagem relacional em **PostgreSQL** via **Prisma ORM** e interface reativa em **React**.

### 6. 👟 Pé Direito — E-commerce WebAPI
API RESTful para e-commerce construída em **Python** com **Flask**, **Flask-SQLAlchemy** e **SQLite**, estruturada com autenticação segura via **Bearer Token** e implantada em ambiente de nuvem.
